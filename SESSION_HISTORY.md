# 99ism.ru - Сессия разработки

## 📋 Резюме работы

В этой сессии была добавлена **полная система регистрации и аутентификации** вместо старой системы с кодами друзей.

## 🔧 Основные изменения

### 1. **Убрана анимация переходов между разделами** (64b9d9a)
- Убрана fade-in/fade-out анимация при переходе между вкладками
- Переходы теперь мгновенные

### 2. **Улучшена видимость кнопки закрытия** (c8adc99)
- Увеличена видимость крестика (X) на мобильных
- Добавлены явные размеры SVG
- Добавлено `flex-shrink:0` чтобы кнопка не сжималась

### 3. **Исправлено положение меню на iPhone** (33c0b03)
- Обновлена функция `setAppHeight()` чтобы учитывать safe-area-inset-bottom
- Меню теперь правильно прижимается к низу на iPhone с Home Indicator

### 4. **Новая система регистрации и аутентификации** (e8fb4dc)
- ❌ Удалены коды друзей (которые обновлялись и требовали переадресации)
- ✅ Добавлена регистрация по **никнейму + пароль**
- ✅ Добавлен вход в существующий аккаунт
- ✅ Друзья добавляются по **никнейму** вместо кодов
- ✅ Все аккаунты сохраняются в localStorage

### 5. **Восстановление пароля** (a72067d)
- Добавлена ссылка "Забыли пароль?"
- Трёхэтапный процесс восстановления:
  1. Ввод никнейма
  2. Ввод ответа на контрольный вопрос
  3. Установка нового пароля

### 6. **Контрольные вопросы при регистрации** (aa478d8)
- Пользователь выбирает/вводит контрольный вопрос при регистрации
- Требуется ввод правильного ответа при восстановлении пароля
- **4 предустановленных вопроса:**
  - "Какое твоё любимое имя Аллаха?"
  - "Город твоего рождения?"
  - "Имя питомца?"
  - "Любимый цвет?"

### 7. **Пользовательские контрольные вопросы** (f162770)
- Добавлена опция "📝 Свой вопрос"
- Пользователь может написать свой контрольный вопрос

### 8. **Кнопка показать/скрыть пароль** (c60b3ba)
- Добавлен золотой глазик (👁️) рядом с полем пароля
- Клик переключает между показом и скрытием пароля
- Иконка меняется в зависимости от состояния

### 9. **Защищённое меню выхода** (0c4907b)
- Убрана кнопка "Выход" из основной области
- Добавлено меню с иконкой трёх точек (⋮)
- Кнопка "Выход" находится в скрытом меню (красного цвета)
- Предотвращает случайный выход из аккаунта

### 10. **Сохранение сессии** (a4a4a47, 4b29a9c)
- Улучшена функция `initProfile()` с обработкой ошибок
- Добавлены вспомогательные функции для работы с хранилищем:
  - `saveUsername()` - сохраняет в localStorage И sessionStorage
  - `getUsername()` - читает из localStorage или sessionStorage (fallback)
  - `clearUsername()` - удаляет из обоих хранилищ
- Гарантирует сохранение сессии даже если localStorage ограничен

## 🎯 Текущее состояние

### ✅ Что работает:
- Регистрация с никнеймом, паролем и контрольным вопросом
- Вход в аккаунт
- Восстановление пароля через контрольный вопрос
- Добавление друзей по никнейму
- Сохранение сессии при перезагрузке (localStorage + sessionStorage)
- Защищённое меню выхода
- Показ/скрытие пароля
- Корректное позиционирование меню на iPhone
- Улучшенная видимость кнопок на мобильных
- Мгновенные переходы между разделами

### ❌ Что не реализовано:
- **Синхронизация между устройствами** (требует бэкенда)
- **Облачное хранилище** прогресса (требует API)
- **Экспорт/импорт прогресса** (был, потом удалён)

## 📝 Примечания

- Все данные хранятся локально в браузере (localStorage + sessionStorage)
- При очистке кэша браузера все аккаунты и прогресс будут удалены
- На production сайте (https://99ism.ru) сессия сохраняется нормально
- Локальное тестирование с `file://` протоколом может иметь ограничения с localStorage
